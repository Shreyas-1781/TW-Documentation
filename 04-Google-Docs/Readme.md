# Google Docs

## 1. Introduction

Google Docs is a cloud-based word processor provided by Google Workspace. It allows users to create, edit, format and share documents online.

It supports real-time collaboration, making it useful for academic work, reports, proposals and team documentation.

## 2. Key Features

- Real-time collaboration between multiple users.
- Rich text formatting and document styling.
- Comments and suggestions for reviewing documents.
- Automatic saving and version history.
- Importing and exporting different file formats.
- Integration with other Google Workspace applications.

## 3. Creating and Structuring Documents

A document can be created using a blank page or a built-in template.

Google Docs provides templates for reports, meeting notes, manuals and other documents.

Documents can be structured using:
- Headings and subheadings.
- Numbered and bulleted lists.
- Tables and images.
- Footnotes and equations.

## 4. Paragraph Styles and Formatting

Google Docs provides different paragraph styles:

- Title
- Subtitle
- Heading 1
- Heading 2
- Normal text

Using heading styles creates a clear document hierarchy and allows users to generate an automatic Table of Contents.

Consistent formatting improves readability and accessibility.

## 5. Collaboration and Sharing

Google Docs allows multiple users to work on the same document simultaneously.

The Share option allows users to invite collaborators through email or a link.

Three common access permissions are:

- **Viewer:** Can only view the document.
- **Commenter:** Can view and add comments.
- **Editor:** Can make changes to the document.

Other collaboration features include:
- Adding and resolving comments.
- Assigning comments to collaborators.
- Using Suggesting mode to propose tracked changes.
- Viewing live edits and collaborator cursors.

## 6. Version History and Recovery

Google Docs automatically saves document changes.

The Version History feature allows users to:
- View previous versions.
- Identify changes made over time.
- Restore an earlier version.
- Name important versions for milestones such as submission or approval.

It helps prevent accidental loss of important information.

## 7. Images, Drawings and Diagrams

Google Docs supports visual elements to improve document presentation.

**Inserting images:**

Use Insert → Image to add images from:
- Computer uploads.
- Google Drive.
- Google Photos.
- Web search or camera.

**Creating drawings:**

Use Insert → Drawing to create simple diagrams using shapes, arrows and lines.

External tools such as Lucidchart and diagrams.net can also be integrated.

## 8. Tables and Lists

Tables are useful for organizing information, comparing data and creating schedules.

Google Docs supports:
- Bulleted lists.
- Numbered lists.
- Checklists.
- Custom tables.

These features make information easier to understand and organize.

## 9. Equations and Code Snippets

Google Docs provides an equation editor through Insert → Equation.

It supports mathematical symbols and basic LaTeX-style mathematical input.

For code snippets, a monospace font can be used to distinguish code from normal text.

For larger code blocks, add-ons or external formatting tools may be used.

## 10. Templates and Formatting Tools

Google Docs provides built-in templates for reports and project proposals.

Additional formatting tools include:
- Headers and footers.
- Page numbering.
- Find and replace.
- Spelling and grammar checks.
- Automatic text suggestions.

## 11. Citations and Bibliography

Google Docs includes a citation tool under Tools → Citations.

It supports common citation styles:
- MLA
- APA
- Chicago

Users can add sources, insert in-text citations and automatically generate a bibliography.

Citation managers such as Zotero and Mendeley can also be integrated using add-ons.

## 12. Exporting and Publishing

Documents can be downloaded in different formats, including:

- PDF
- DOCX
- ODT
- HTML
- RTF
- TXT

Google Docs also provides a Publish to web option for making documents publicly accessible.

It can be used alongside Google Slides and Google Sheets.

## 13. Security and Permissions

Google Docs provides document-level access controls.

Users can:
- Restrict access to specific people.
- Set viewer, commenter or editor permissions.
- Remove access when required.
- Use expiration dates for access where supported.

Google Workspace administrators can also manage organization-wide sharing policies.

## 14. Integration with Other Tools

Google Docs integrates with several applications and services.

Examples include:
- Google Drive for file storage.
- Google Calendar for scheduling.
- Google Meet for meetings.
- Google Forms for collecting responses.
- Trello and Asana for project management.
- GitHub and diagramming tools through integrations or add-ons.

Google Apps Script can also be used to automate tasks.

## 15. Best Practices

- Follow a consistent formatting style.
- Use headings and a Table of Contents.
- Organize documents into appropriate sections.
- Assign suitable editing and reviewing permissions.
- Resolve comments and suggestions after reviewing.
- Maintain important versions and export milestone documents.
- Keep documents clear, accurate and easy to understand.

## 16. Doxygen vs Google Docs

| Feature | Doxygen | Google Docs |
|---|---|---|
| Purpose | Code and API documentation | General documentation |
| Collaboration | Mainly through code reviews | Real-time collaboration |
| Rich media | Code-linked diagrams | Images, tables and drawings |
| Output | HTML, LaTeX, PDF and more | PDF, DOCX, HTML and more |
| Best use | Software documentation | Reports, proposals and notes |

### When to Use Which?

- **Doxygen:** Best for automatically generating code-linked API documentation.
- **Google Docs:** Best for collaborative editing, reports and general-purpose documents.
- **Both together:** Google Docs can be used for project planning and design documents, while Doxygen handles technical code documentation.

## 17. Conclusion

Google Docs is a useful tool for creating, formatting and collaborating on documents. Its sharing, commenting, version history and integration features make it suitable for academic and professional documentation.
