# Technical Writing – Documentation Repository

## About This Repository

This repository contains documentation, practical examples, and learning materials prepared as part of the Technical Writing (TW) course at Malaviya National Institute of Technology (MNIT), Jaipur.

## Topics Covered

1. **LaTeX** – Document preparation, formatting, mathematical equations, tables, and figures.
2. **Beamer** – Creating professional presentations using LaTeX.
3. **Doxygen** – Generating software documentation from source code.
4. **Google Docs** – Document creation, collaboration, formatting, and sharing.
5. **Git** – Version control, repository management, branching, and merging.
6. **GitHub** – Hosting repositories, collaboration, and project management.

## Repository Structure

- `01-LaTeX/`
- `02-Beamer/`
- `03-Doxygen/`
- `04-Google-Docs/`
- `05-Git/`
- `06-GitHub/`

## Purpose

The purpose of this repository is to maintain organized documentation of the concepts learned and practical work completed during the Technical Writing course.
